# Results

This directory contains outputs generated by the Python and R analysis scripts in this repository.

The scripts are independent and were developed for different components of the research project. There is therefore no single sequential analysis pipeline, and individual results should be associated with the script that generated them.

## Types of outputs

### Pseudoneutralisation curve fitting and diagnostic plots

`02_pv.neutralisation.graphs.py` fits four-parameter logistic (4PL) curves to pseudoneutralisation data and generates graphical diagnostics of the fitted curves.

Outputs:
1. fitted neutralisation curves in input directory /outputs/, separated by pseudovirus
2. pv_neutralisation_results.xlsx with pVNT50 and pVNT90 data

### ELISA heatmaps

`03_heatmap.py` generates a .png heatmap from ELISA data contained in a user-selected Excel workbook in the same directory.

### ELISA and pseudoneutralisation analysis

`04_analyse.ELISA.PV.py` performs analyses of ELISA and pseudoneutralisation data and generates results workbooks.

The script also generates pseudoneutralisation graphs using the results produced by the analysis.

Outputs may therefore include, depending on user input and selection:

* ELISA analysis results (sheet in results workbook);
* pseudoneutralisation analysis results (sheet in results workbook);
* pseudoneutralisation graphs (new folder).

### Histograms

`05_histograms` generates overall and subgroup histograms from a user-selected Excel worksheet.

These plots are used to visualise distributions of the variables being analysed.
Plots will be outputted into a new folder in the working directory.

### Regression analysis

`07_one.regression` performs a regression analysis using user-selected columns from an Excel workbook.

The resulting outputs contain the model results associated with the selected variables.
Results will be outputted into a new folder in the working directory.

`09_multivariate.stepwise.regression.py` performs univariable and multivariable logistic regression analyses from an Excel worksheet, including stepwise multivariable model selection.

Results will be outputted into a new Excel workbook in the working directory.

### UK county plots

`08_plot.uk.counties.py` generates plots of seroprevalence by UK county group from an Excel dataset.

Results will be outputted into a new .csv file in the working directory and a .png map of the UK.

### Fisher's exact test

`06_fisher.exact.rmd` performs Fisher's exact tests with Benjamini-Hochberg adjustment for multiple comparisons.

Results will be outputted into a new Excel workbook in the working directory and a .html R markdown file.

### Protein concentration estimation

`01_protein.concentration.empiria.Rmd` estimates protein concentration from an SDS-PAGE BSA standard curve. Results are appended to the input workbook as a new sheet.

## Relationship to the thesis

The outputs in this directory correspond to analyses, tables and figures described in the associated PhD thesis.

Where applicable, individual output files should be interpreted together with:

* the script that generated them;
* the relevant thesis Methods section;
* the corresponding Results section; and
* the input dataset used for the analysis.

## Reproducibility

Generated results depend on the input data and the software environment used to perform the analysis.

The repository records the relevant Python and R software dependencies. However, the original study data are not included where their distribution is restricted.

Consequently, the presence of an analysis script in this repository does not necessarily mean that the corresponding result can be independently regenerated from the repository alone.

## Output files

Only selected outputs may be retained in this repository. Intermediate files, temporary files and large generated datasets may be omitted where they are not necessary for understanding or reproducing the analysis.

Where an output is included, its filename should indicate its contents and, where useful, the analysis or script that generated it.

## Interpretation

The files in this directory are computational outputs and should not be interpreted independently of the statistical methodology described in the thesis.

The thesis remains the primary source for the rationale, methodological decisions, statistical interpretation and scientific conclusions associated with these analyses.
