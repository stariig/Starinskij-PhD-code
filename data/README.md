# Data

This directory contains documentation relating to the input datasets used by the Python and R scripts in this repository.

The analysis scripts generally read data from Excel workbooks selected by the user at runtime. Raw study data are not included in this repository where their distribution is restricted by ethical, data-protection, institutional or other confidentiality requirements.

## Input data

The analyses in this repository use several types of input data, including:

### ELISA data

ELISA datasets contain sample-level ELISA measurements and associated metadata required for calculation, visualisation and statistical analysis.

These data are used by, among others:

* `03_heatmap.py`
* `04_analyse.ELISA.PV.py`
* `05_histograms`
* `07_one.regression`
* `08_plot.uk.counties.py`
* `09_multivariate.stepwise.regression.py`

The exact column names and structure required depend on the analysis being performed.

### Pseudoneutralisation data

Pseudoneutralisation datasets contain measurements from pseudoneutralisation assays and the associated sample information required for curve fitting and statistical analysis.

These data are used by:

* `02_pv.neutralisation.graphs.py`
* `04_analyse.ELISA.PV.py`

### Protein concentration data

`01_protein.concentration.empiria.Rmd` uses SDS-PAGE measurements from a BSA standard curve to estimate protein concentration.

### Categorical/count data

`06_fisher.exact.rmd` uses categorical or count data appropriate for Fisher's exact test.

## Specific data format

Most analyses use Excel workbooks (`.xlsx` or compatible Excel formats). Individual scripts allow the user to select the relevant workbook, and in some cases a specific worksheet, when the script is run.

The required variables, column names and data structure may therefore differ between analyses.

Users attempting to reproduce an analysis should refer to the individual script and the corresponding Methods section of the thesis for the required input structure. Example empty/mock input datasets are located in data/example.inputs/

### 01_protein.concentration.empiria.Rmd
LI-COR	Empiria Studio	3.3 output file from the Protein Gel module. Script will ask for workbook, sheet must be called "700". Type should be "Sample" or "Positive". Rows with type "Ignore" will be excluded from analysis.

Example file(s):
* `01_example.xlsx`

### 02_pv.neutralisation.graphs.py

Workbook containing neutralisation data.
Column 1: Titre. Absolute value, i.e. dilution 1:50 is "0.02". Control dilution is typically 1.
Row 1, columns 2 onwards: name of sample or control. Sample name: "[pv.name] [sample.name]". Control name: "[pv.name] pos" OR "neg".
Row 2 onwards, columns 2 onwards: uminescence data.

Example file(s):
* `02_example.xlsx`

### 03_heatmap.py

Workbook containing categorical and continuous data. Sheet named "heatmap" will be used.
Column assignment is non-flexible.
column_names = ["condition_1", "condition_2", "condition_3", "condition_4", "sample", "ODn"]

Example file(s):
* `03_example.xlsx`

### 04_analyse.ELISA.PV.py

Layout workbook containing platemap and metadata for ELISA and PV neutralisation.
Optional: ROUT (FDR = 1%) outlier detection results for the ELISA dataset (sheet "outliers" in Layout workbook).
Optional: .xls or .csv workbook generated by SpectraMax M3 spectrophotometer containing ELISA data.
Optional: .xlsx workbook generated by GloMax Discover instrument containing PV neutralisation data.

Example file(s):
* `04_example.xlsx` - metadata input
* `26.01.01.PV01.xlsx` - pseudoneutralisation raw file generated using OneGlo protocol on  GloMax Discover instrument (Promega)
* `26.01.01_DSS.PL1.2.3.4.xls` - 450 nm and 620 nm absorbance data read on a SpectraMax M3 plate reader (Molecular Devices)

## Data availability

The original study datasets are not included in this repository.

Where permitted, example or synthetic datasets may be provided to demonstrate the expected input format. Such datasets are not intended to reproduce the study results unless explicitly stated.

## Data provenance

The datasets analysed by these scripts were generated or compiled as part of the research described in the associated PhD thesis.

Further information on sample collection, laboratory procedures, data processing and variable definitions is provided in the thesis.

## Confidentiality and data protection

No confidential or personally identifiable information should be added to this repository.

When using these scripts with the original study data, users are responsible for ensuring that data are handled in accordance with applicable ethical approvals, data-management requirements and institutional policies.

## Using the scripts with the data

The scripts do not assume a single repository-wide input dataset. Instead, the required workbook is selected by the user when an analysis is performed.

The general workflow is therefore:

1. Prepare the appropriate input dataset in the structure required by the relevant script.
2. Run the relevant Python or R script.
3. Select the required Excel workbook or worksheet when prompted.
4. Review the generated output and diagnostic files.
5. Refer to the thesis Methods and the script documentation for details of the analysis.
