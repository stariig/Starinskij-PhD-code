**Department/School:** College of Medical, Veterinary, and Life Sciences. School of Infection & Immunity
**Year:** 2026

The repository contains the analysis code corresponding to the version of the analyses reported in the submitted thesis.

## Analyses

The scripts in this repository are independent and were used for different components of the research project. They are not intended to be executed sequentially.

### Python

#### `02_pv.neutralisation.graphs.py`

Fit 4-parameter logistic curves to pseudoneutralisation data and generate diagnostic plots.

#### `03_heatmap.py`

Create an ELISA heatmap from a user-selected Excel workbook.

#### `04_analyse.ELISA.PV.py`

Analyse ELISA data from a user-selected Excel workbook and generate a results workbook.
	Analyse PV neutralisation data from a user-selected Excel workbook and generate a results workbook.
	Generatise PV neutralisation graphs from the results workbook.

#### `05_histograms`

Create overall and subgroup histograms from a user-selected Excel sheet.

#### `07_one.regression`

Run a regression using columns selected from an Excel workbook.

#### `08_plot.uk.counties.py`

Plot seroprevalence by UK county group from a user-selected Excel file.

#### `09_multivariate.stepwise.regression.py`

Run univariable and multivariable logistic regression from an Excel sheet.

### R

#### `01_protein.concentration.empiria.Rmd`

Estimate protein concentration from SDS-PAGE BSA standard curve.

#### `06_fisher.exact.rmd`

Run a fisher exact test with Benjamini-Hochberg adjustment.

## Software environment
### Python
Python 3.14.7
pip 26.0.1

Python packages and versions are specified in:
`python/requirements.txt`

To recreate the Python environment using a virtual environment:

```bash
python -m venv .venv
```

Activate the environment on Windows:

```bash
.venv\Scripts\activate
```

Install the required packages:

```bash
pip install -r python/requirements.txt
```

## Reproducibility

The scripts were developed and tested using the software versions and package versions documented in this repository.

To reproduce an analysis:

1. Obtain the required input data and place them in the locations described in `data/README.md`.
2. Recreate the relevant Python or R software environment.
3. Run the individual script corresponding to the required analysis.
4. Refer to the script documentation and the corresponding Methods section of the thesis for details of the analytical procedure.

The statistical methodology and analytical decisions are described in the thesis and are not intended to be inferred solely from the source code.
